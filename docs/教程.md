# 第二部分：核心概念速成（边做边学）

## 2.1 面向对象
Python 里"对象"就像一个真实的东西——有名字（变量名）、有属性（颜色、大小）、能做动作（方法）。我们用"类（class）"来定义对象的蓝图：
```python
class Cat:                   # 蓝图：猫
    def __init__(self, name):  # 初始化（生下来）
        self.name = name        # 每只猫都有名字
        self.color = "白"
    def meow(self):             # 动作：叫
        print(f"{self.name}: 喵～")

kitty = Cat("小白")        # 出生一只叫"小白"的猫
kitty.meow()                # 小白：喵～
```
整个 netcheck 都是这种风格：每个 Tab 是一个 `class`，每个 Tab 上面的"按钮""文本框"是它的属性，每个按钮被点击后调用的函数是它的方法。

## 2.2 事件循环
GUI 程序有个共同特点：用户点哪个按钮就响应哪个，永远等着。所以：
- `app.exec()` 启动一个**死循环**（事件循环）
- 操作系统把"用户点了一下鼠标"这件事告诉程序
- 程序找到对应按钮的回调函数去执行
- 执行完回到死循环，继续等

## 2.3 信号与槽（Signal / Slot）
PySide6 里**信号（Signal）** 是个特殊函数，只能"发出去"，不能直接调用。**槽（Slot）** 是接收信号的函数。把两者接起来叫"连接（connect）"。

```python
button.clicked.connect(my_function)
# 意思：button 被点的时候，调一下 my_function
```

为什么需要它？因为我们的网络操作要"等网络回来数据"——这段时间不应该卡死窗口。所以：
- 把"发请求"放到子线程（QThread）里
- 子线程干完活，发一个信号
- 主线程收到信号，刷新界面

## 2.4 多线程
默认情况下 Python 一个进程里只有一条线。如果你在一条线上 `time.sleep(5)`，那整个程序就卡住 5 秒。GUI 程序卡住就意味着窗口冻住、点不动。

解决办法：开一条新线程干慢活。
```python
from threading import Thread

def slow():
    print("开始干慢活……")
    time.sleep(3)
    print("干完了")

t = Thread(target=slow)
t.start()                 # 启动新线程
print("我不用等，可以继续做别的")
```
PySide6 里专门的 `QThread` 类就是为了这个，但要复杂一些（见后面的"测速"部分）。

## 2.5 HTTP 网络请求
测速用 `http.client`（Python 自带，不需装），`urllib.request` 也行，但 `http.client` 更底层更可控：
```python
import http.client, urllib.parse

url = "https://mirrors.tuna.tsinghua.edu.cn/ubuntu-releases/24.04.4/ubuntu-24.04.4-desktop-amd64.iso"
pu = urllib.parse.urlsplit(url)
conn = http.client.HTTPSConnection(pu.hostname, 443, timeout=3)
conn.request("GET", pu.path, headers={"User-Agent": "Mozilla/5.0"})
resp = conn.getresponse()           # 拿到服务端回应
data = resp.read(1024)              # 读 1KB 数据
print(f"状态码: {resp.status}  读了 {len(data)} 字节")
```

## 第 3 步：第一个真功能 — Ping 一个主机
文件：`step3_ping.py`

```python
import sys, subprocess, re
from PySide6.QtWidgets import (QApplication, QMainWindow, QWidget,
                               QVBoxLayout, QHBoxLayout, QLabel,
                               QLineEdit, QPushButton, QPlainTextEdit)

# ① 定义"做一件事"的函数（ping 一个主机）
def ping(host: str, count: int = 4) -> tuple[bool, float, float]:
    """
    返回 (通不通, 平均延迟 ms, 丢包率 %)
    用 Windows 自带的 ping 命令
    """
    try:
        # subprocess.run 跑子进程，capture_output=True 抓住它的输出
        out = subprocess.run(
            ["ping", "-n", str(count), "-w", "1500", host],
            capture_output=True, timeout=count * 2 + 5
        ).stdout.decode("gbk", "ignore")
    except Exception:
        return False, 0.0, 100.0

    # 从输出里找"来自 xx 的回复"行，提取延迟
    times = []
    for line in out.splitlines():
        if "来自" in line or "Reply from" in line:
            m = re.search(r"[=<>]\s*(\d+)\s*ms", line, re.I)
            if m: times.append(int(m.group(1)))

    if not times:
        return False, 0.0, 100.0
    avg = sum(times) / len(times)
    loss = (count - len(times)) / count * 100
    return True, avg, loss

# ② 拼窗口
```

### 关键概念讲解
- **`subprocess.run`**：跑外部命令（ping.exe、ipconfig.exe、tracert.exe……都是 Windows 自带的）
- **`capture_output=True`**：把子进程的输出抓回来
- **`.stdout.decode("gbk", "ignore")`**：Windows cmd 输出是 GBK 编码，Python 默认是 UTF-8，所以要转码；`"ignore"` 是遇到乱码就跳过
- **正则 `re.search(r"[=<>]\s*(\d+)\s*ms", line)`**：从"时间=23ms"里把 23 抓出来

## 第 4 步：进阶 Ping — 选项 + 多次 + TCPing
文件：`step4_高级ping.py`

这一节开始越来越接近真实 netcheck。我把关键代码全列出来，请务必**亲手抄**一遍（不要直接复制粘贴 —— 抄代码能练手感）。

```python
# step4_高级ping.py
# 教学：在 step3 基础上加：
#   1. 让用户自己选 ping 几次
#   2. 实时把每次结果打印出来
#   3. 加 TCPing（连一个 TCP 端口，看通不通）

import sys, subprocess, re, socket, time
from PySide6.QtWidgets import (QApplication, QMainWindow, QWidget,
    QVBoxLayout, QHBoxLayout, QLabel, QLineEdit, QPushButton,
    QPlainTextEdit, QComboBox, QSpinBox)
from PySide6.QtCore import QThread, Signal

# ① 工具函数
def ping_once(host, timeout_ms=1500):
    """一次 ping：返回 (通, 延迟ms 或 None)"""
    try:
        p = subprocess.run(
            ["ping", "-n", "1", "-w", str(timeout_ms), host],
            capture_output=True, timeout=timeout_ms/1000+3
        )
        out = p.stdout.decode("gbk", "ignore")
    except Exception:
        return False, None
    for line in out.splitlines():
        if ("来自" in line or "Reply from" in line) and "TTL" in line.upper():
            m = re.search(r"[=<>]\s*(\d+)\s*ms", line, re.I)
            if m: return True, int(m.group(1))
    return False, None

def tcp_ping(host, port, timeout_ms=1500):
    """TCPing：连一次 TCP 端口"""
    try:
        ip = socket.getaddrinfo(host, port, socket.AF_INET,
                                socket.SOCK_STREAM)[0][4][0]
    except socket.gaierror:
        return False, None, "域名解析失败"
    s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    s.settimeout(timeout_ms/1000)
    t0 = time.perf_counter()
    try:
        s.connect((ip, port))
        rtt = (time.perf_counter() - t0) * 1000
        return True, rtt, ""
    except (socket.timeout, ConnectionRefusedError, OSError) as e:
        return False, None, type(e).__name__
    finally:
        s.close()

# ② 后台线程：QThread 子类
# 这是 PySide6 多线程的核心：UI 线程 = 主线程；干活 = 子线程
class PingWorker(QThread):
    # 每次结果用 signal 发回主线程
    sample = Signal(int, bool, object)   # (第几次, 通, 延迟)
    done = Signal(dict)                  # 全部完成

    def __init__(self, host, count, mode, port=443, timeout=1500):
        super().__init__()
        self.host, self.count, self.mode = host, count, mode
        self.port, self.timeout = port, timeout

    def run(self):
        # 这个 run() 是子线程执行的
        ok_n, total_rtt = 0, []
        for i in range(1, self.count + 1):
            if self.mode == "ping":
                ok, rtt = ping_once(self.host, self.timeout)
            else:
                ok, rtt, _ = tcp_ping(self.host, self.port, self.timeout)
            if ok:
                ok_n += 1
                if rtt is not None: total_rtt.append(rtt)
            self.sample.emit(i, ok, rtt)        # ★ 发信号给主线程
        loss = (self.count - ok_n) / self.count * 100
        avg = sum(total_rtt)/len(total_rtt) if total_rtt else 0
        self.done.emit({"ok": ok_n, "n": self.count, "loss": loss, "avg": avg})

# ③ 界面
app = QApplication(sys.argv)
win = QMainWindow(); win.setWindowTitle("netcheck v0.4 - 高级 Ping"); win.resize(700, 400)
page = QWidget(); v = QVBoxLayout(page)

row = QHBoxLayout()
row.addWidget(QLabel("目标："))
ed = QLineEdit("www.baidu.com")
row.addWidget(ed, 1)
row.addWidget(QLabel("模式："))
cb_mode = QComboBox(); cb_mode.addItems(["ping", "tcping"])
row.addWidget(cb_mode)
row.addWidget(QLabel("次数："))
sp = QSpinBox(); sp.setRange(1, 30); sp.setValue(4)
row.addWidget(sp)
row.addWidget(QLabel("端口："))
ed_port = QLineEdit("443"); ed_port.setFixedWidth(60)
row.addWidget(ed_port)
btn = QPushButton("开始")
row.addWidget(btn)
v.addLayout(row)

log = QPlainTextEdit(); log.setReadOnly(True); v.addWidget(log, 1)

def on_start():
    btn.setEnabled(False)
    log.clear()
    target = ed.text().strip()
    worker = PingWorker(target, sp.value(), cb_mode.currentText(),
                        int(ed_port.text() or 443), 1500)
    worker.sample.connect(lambda i, ok, rtt: log.appendPlainText(
        f"[{i}] {'通 '+str(rtt)+'ms' if ok else '不通'}"
    ))
    worker.done.connect(lambda s: (log.appendPlainText(
        f"** 完成：{s['ok']}/{s['n']} 通，丢包 {s['loss']:.0f}%，平均 {s['avg']:.1f}ms **"),
        btn.setEnabled(True)))
    worker.start()

btn.clicked.connect(on_start)
win.setCentralWidget(page); win.show()
sys.exit(app.exec())
```

### 关键概念讲解（这节是真正难的部分）
- **`QThread` 子类**：把要干的活放在 `run()` 里，主线程 `worker.start()` 启动
- **`Signal(...)` 类变量**：定义信号，参数是信号"消息"的格式（这里是 int, bool, object）
- **`emit(...)`**：从子线程发信号
- **`connect(...)`**：主线程订阅信号 —— `sample.connect(...)` 表示收到一次 sample 就调一下后面的函数
- **为什么用信号？** 因为子线程**不能直接动界面**（会崩）。必须把"干完的结果"通过信号传给主线程，让主线程去刷新。

## 第 5 步：网段扫描 — 并行 ping 一堆 IP
现在能 ping 一个了，**网段扫描 = 把 192.168.1.1 到 192.168.1.254 全 ping 一遍**。

```python
# step5_网段扫描.py
# 教学：用 ThreadPoolExecutor 并行 ping 整段
import sys, ipaddress, subprocess, re
from concurrent.futures import ThreadPoolExecutor, as_completed
from PySide6.QtWidgets import (QApplication, QMainWindow, QWidget,
    QVBoxLayout, QHBoxLayout, QLabel, QLineEdit, QPushButton,
    QPlainTextEdit, QSpinBox, QGridLayout, QGroupBox)
from PySide6.QtCore import QThread, Signal

# 复用第 4 步的 ping_once
def ping_once(host, timeout_ms=1000):
    try:
        p = subprocess.run(
            ["ping", "-n", "1", "-w", str(timeout_ms), host],
            capture_output=True, timeout=timeout_ms/1000+2
        )
        out = p.stdout.decode("gbk", "ignore")
    except Exception:
        return False
    for line in out.splitlines():
        if ("来自" in line or "Reply from" in line) and "TTL" in line.upper():
            return True

# 把 "192.168.1.0/24" 这种字符串展开成 IP 列表
def parse_targets(text):
    t = (text or "").strip()
    if "/" in t:
        net = ipaddress.ip_network(t, strict=False)
        return [str(h) for h in net.hosts()]
    if "-" in t:
        a, b = t.split("-", 1)
        prefix = a.rsplit(".", 1)[0]
        start, end = int(a.rsplit(".", 1)[1]), int(b)
        return [f"{prefix}.{i}" for i in range(start, end + 1)]
    return [t]

# 后台线程：扫整段
class ScanWorker(QThread):
    done_host = Signal(str, bool)   # (host, 通不通)
    finished = Signal(int, int)     # (通的, 总的)

    def __init__(self, hosts, conc=20):
        super().__init__()
        self.hosts = hosts
        self.conc = conc

    def run(self):
        # ThreadPoolExecutor 真的并行（多核）
        with ThreadPoolExecutor(max_workers=self.conc) as ex:
            futures = {ex.submit(ping_once, h): h for h in self.hosts}
            for fut in as_completed(futures):
                h = futures[fut]
                try:
                    ok = fut.result()
                except Exception:
                    ok = False
                self.done_host.emit(h, ok)
        ok_n = sum(1 for h in self.hosts
                   if self._ok.get(h, False))
        self.finished.emit(ok_n, len(self.hosts))
        # ↑ 注意：上面 self._ok 没真的存。这只是示意结构。
        # 实战里你应该用 dict 把"每个 host 的结果"存起来。
```

## 第 13 步：宽带测速（最核心、最难）
原理：
1. **下载** —— `http.client` 连一个公开测速点，分块读取，定时器记"已读字节 / 已用秒数" = 速率
2. **多连接** —— 用 `ThreadPoolExecutor` 同时开 4 条下载，把单 TCP 限速绕开
3. **稳态** —— 跳过开头 2 秒（TCP 慢启动 + ISP 突发加速），只测稳态窗口
4. **上传** —— 用 `http.client` 的 `putrequest/putheader/sendall` 手动分块 POST

```python
import time
import http.client, urllib.parse

def download_speed(url, max_time=8, streams=4, skip_sec=2.0):
    """★ 多连接 + 稳态测速 ★"""
    pu = urllib.parse.urlsplit(url)
    host, port = pu.hostname, pu.port or 443
    path = pu.path + ("?" + pu.query if pu.query else "")

    from concurrent.futures import ThreadPoolExecutor
    bytes_lock_total = [0]
    def _one():
        c = http.client.HTTPSConnection(host, port, timeout=3)
        c.request("GET", path, headers={"User-Agent": "Mozilla/5.0"})
        r = c.getresponse()
        if r.status != 200: return
        while True:
            chunk = r.read(64*1024)
            if not chunk: break
            bytes_lock_total[0] += len(chunk)
    with ThreadPoolExecutor(max_workers=streams) as ex:
        list(ex.map(lambda _: _one(), range(streams)))

    # 简化版，没做稳态跳过（完整版见 netcheck.py）
    elapsed = max_time
    return bytes_lock_total[0] / elapsed

speed = download_speed("https://speed.cloudflare.com/__down?bytes=50000000")
print(f"速率: {speed/1024/1024:.1f} MB/s  =  {speed*8/1e6:.0f} Mbps")
```

`http.client` 测速的**关键细节**（最容易踩的坑）：

```python
# ❌ 错：这样没法"快速失败"
c.request("GET", path)               # 慢服务器会让这里卡满 timeout
r = c.getresponse()

# ✅ 对：拆成两阶段超时
c = http.client.HTTPSConnection(host, port, timeout=2.5)   # 阶段 1：连接最多 2.5s
c.connect()                          # 在这个 timeout 范围内必须连上
c.sock.settimeout(max_time)          # 阶段 2：连上后放宽到 max_time
c.request("GET", path)               # 进入读取
r = c.getresponse()                  # 这下不会傻等
```

# 第四部分：常见问题与排错

## 4.1 pip install 慢/失败
**现象**：`pip install PySide6` 卡半天
**解决**：换镜像
```bash
pip install PySide6 -i https://mirrors.aliyun.com/pypi/simple/ --trusted-host mirrors.aliyun.com
```

## 4.2 ModuleNotFoundError: No module named 'PySide6'
**原因**：在错误的 Python 环境装包
**解决**：先 `python -c "import sys; print(sys.executable)"` 看 Python 装哪了，再 `pip --version` 看 pip 是哪个 Python 的。两者必须一致。

## 4.3 pyinstaller 打包报错 "Unable to find Qt"
**原因**：PySide6 没装在该 Python 环境
**解决**：重新 `pip install PySide6` 然后再 `pyinstaller`

## 4.4 程序双击闪一下就退出
**原因**：有 Python 异常被抛了
**解决**：在 cmd 里 `python netcheck.py` 跑（不是双击），能看到红色报错
或者下载 **本项目最新版的 v9.6** —— v9.6 加了全局异常兜底：异常会写到 `%LOCALAPPDATA%\netcheck\error.log` 并弹窗。

## 4.5 窗口卡死 / 转圈
**原因**：在主线程（UI 线程）里干慢活
**解决**：把慢活放 `QThread` 子线程（见第 4 步）

## 4.6 在别的电脑上程序"自己退出"
**原因**（重要！）：`QThread` 释放不当。**绝不能**在线程还在跑的时候 `self.worker = None`。详见本项目 v9.6 修复记录。简单做法：把 worker 对象塞进一个 `list` 里托住引用，不要主动释放。

## 4.7 测速显示 0 / 节点失败
- 检查网：能 ping 通外网吗？
- 检查节点：清华 / 北大 / 哈工大镜像偶尔会临时挂；如果不通用 `ipconfig /all` + `ping 8.8.8.8` 排查
- 防火墙可能挡了 python.exe 的出站
